NexusAI Desktop RAG Document Assistance Upgrade

Scope
- This patch is intentionally focused on the attachment/document path.
- It does not change model runtime selection, GPU logic, Mac runtime detection, chat switching, Image Studio, database schema, online providers, or release packaging.

Changed files
1. src/components/ChatView.tsx
2. src-tauri/src/file_context.rs

What improved
1. Dynamic attachment prompt budgeting
   - The amount of document text sent to the model now adapts to the selected Memory Window and Response Length.
   - This avoids overloading small local models with too much document context.

2. Better RAG retrieval
   - The app ranks indexed chunks using query tokens, simple stemming, phrase matching, file/title boosts, and domain-related term expansion.
   - It handles general summary questions differently from specific questions.
   - It sends only the highest-value sections instead of the full document.

3. Cleaner internal document context
   - Retrieved document sections are now sent with plain delimiters instead of fenced code blocks.
   - This reduces the chance that the model confuses document context with code output.

4. Faster local document answers
   - Indexed sections are limited by a prompt budget.
   - Long sections are trimmed safely.
   - The selected chunks are capped according to the model context window.

5. Quick attachment actions
   - Added quick prompts for Summarize, Key points, Risks, and Explain when attachments are ready.
   - These help demo and real users start document workflows quickly.

6. Better document cleaning
   - Control characters are stripped from extracted text.
   - Repeated headers/footers and page markers are cleaned more aggressively.
   - Chunk sizes are smaller for faster retrieval and less prompt bloat.

Validation
- npm run build passed successfully in the sandbox after installing frontend dependencies.
- Rust/Cargo could not be run in this sandbox because cargo is not installed here. Run cargo check on the target Windows machine before final release.

Recommended tests
1. Normal chat without attachments.
2. Attach a TXT file and ask for a summary.
3. Ask a follow-up question without reattaching the file.
4. Attach a PDF and ask for main risks or key points.
5. Attach a DOCX and ask for a specific section.
6. Use the quick attachment buttons.
7. Confirm response streaming still works.
8. Confirm Image Studio, model selection, and runtime scan still work.

Notes
- This is still a lightweight local lexical RAG system, not a full vector database or embeddings pipeline.
- It is safer and faster than sending the whole document to the local model.
- Future enterprise improvements can add persistent document indexes, embeddings, per-company knowledge bases, and OCR for scanned PDFs.
