# PocketMind Hybrid AI Quick Start

## 1. Install

Follow `INSTALL.md` in your desktop package (Windows, macOS, or Linux).

## 2. First launch

1. Open PocketMind Hybrid AI.
2. Go to **Settings → Deployment**.
3. Review folders, then **Save**.

## 3. Add a chat model

1. Copy model files into the models folder.
2. Open **Models** → scan → select a model → use in chat.

## 4. Company / SOC folders (optional)

1. Copy sanitized company files into `company-data/`.
2. Open **Fortinet Copilot → Grounded SOC Knowledge** → scan & index.

## 5. Knowledge Chat

1. Create a collection for a folder.
2. Scan → build index → ask questions.
